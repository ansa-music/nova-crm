## Правила Firestore

Откат кода возвращает `firestore.rules` целиком (деплой заменяет набор правил, а не
дополняет). Быстрая замена без CI: Firebase Console → Firestore Database → Rules →
история версий → откатить.

## Индексы — единственное, что откат не чистит сам

В CI нет флага `--force`, поэтому деплой создаёт недостающие индексы, но НЕ удаляет
лишние. Всё, что перенос добавит в `firestore.indexes.json`, останется в проекте и после
отката. Приложению это не мешает (лишние индексы только занимают место и чуть замедляют
запись). Убрать руками: Firebase Console → Firestore → Indexes.

## Чего откат кода НЕ вернёт

- **Данные Firestore.** План Spark: ни автоматических бэкапов, ни восстановления на момент
  времени. Удалённый или переписанный документ не вернёт ничто.
- **Файлы в Supabase Storage** (бакет `row-files`): вложения строк, обложки столов,
  аватарки. В базе лежат только ссылки на них.
- **Аккаунты Firebase Auth.** На `uid` завязаны `members/{uid}`, `osdesk_{uid}`,
  `personalZones/{uid}`, `deskObservers/{uid}`, отметки прочитанного. Новые uid = связи
  рвутся.
- **Таблицу `row_records` в Supabase.** Порядок строк столы читают именно оттуда, а свежие
  ячейки — тоже оттуда. Перезапись этой таблицы ломает столы даже при целом Firestore.

## Что сделать ДО старта переноса

1. **Бэкап данных.** Owner → Настройки → вкладка «Бэкап» → «Скачать бэкап workspace».
   Кладёт JSON: сам workspace, участники, столы, их строки и все вкладки со строками.
   Стоит примерно 5–10 тысяч чтений (10–20 % дневной квоты) — делать один раз и после
   сброса квоты (около 12:00–13:00 по Алматы). Файл положить в два места.
   **В бэкап НЕ входят:** заказы, график, рейтинги, аккаунты Грока, личные зоны,
   история изменений, чаты, уведомления, профили `users`. Импорта у этого файла нет —
   восстановление только скриптом.
2. **CSV по столам** (тулбар стола → «Ещё» → «Экспорт CSV») — человекочитаемая страховка,
   чтений не тратит.
3. **Supabase Dashboard → Table Editor → `row_records` → Export CSV.**
4. По желанию, требует входа в firebase: `npx firebase-tools login`, затем
   `npx firebase-tools auth:export users.json --project nurba-6e70d` — список аккаунтов.
5. Файлы не из git уже скопированы в `otkat-2026-09-23\ne-v-git\`.
