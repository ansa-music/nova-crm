# Nova CRM — сборка «Table v2.1» (дополнение)

## Таблица
- **Маркер заполнения (drag-to-fill)** — маленький квадрат в правом нижнем углу выделения:
  потяните вниз или вверх, чтобы заполнить строки значением (или чередующимся набором
  значений, если выделено несколько строк — как в Excel). Предпросмотр диапазона, одна
  команда отмены на всё заполнение, тост «Отменить», автопрокрутка у края.
- **Цветная полоска статуса** слева у каждой строки — таблица читается «полосами»
  без взгляда на столбец статуса.
- **«+ Новая строка»** внизу таблицы (когда нет сужающих фильтров).
- **Быстрый фильтр по дате** — чип «Период»: Сегодня / Вчера / Эта неделя / 7 дней /
  Этот месяц / Прошлый месяц / 30 дней / Этот год; при нескольких столбцах-датах — выбор
  столбца. Границы дней считаются по Алматы.
- **Чип «Мои»** — только строки, где Ответственный совпадает с вашим ником/именем
  (показывается, если такой вариант в списке ответственных есть).
- **Дубли контактов**: если один и тот же телефон (8… и +7… считаются одним номером) или
  email встречается в нескольких строках, в ячейке появляется бейдж «дубль»; клик —
  показать все строки с этим контактом.
- **Кнопки Отменить / Вернуть** в тулбаре (на телефоне — в меню «Ещё»), с подсчётом
  очереди; undo/redo теперь переживают ошибку сети (команда возвращается в стек).
- В канбане кнопка «Открыть карточку» всегда видна на сенсорных экранах.

# Nova CRM — что изменилось (сборка «Table v2», сентябрь 2026)

## Диалоги вместо системных окон (весь сайт)
- Все 26 вызовов `window.confirm` / `window.prompt` заменены на собственные диалоги
  в стиле приложения: `confirmDialog()` и `promptDialog()` (`src/utils/appDialog.ts`,
  хост — `src/components/common/AppDialogHost.tsx`, смонтирован в `AppLayout`).
- У опасных действий красная кнопка и понятное описание последствий; у ввода —
  предзаполненное поле с автовыделением, лимит символов, Enter/Esc.
- Затронуты: удаление столов/вкладок/столбцов/строк/сообщений/участников/workspace,
  переименования, новые кастомные поля, отчёты личного пространства, Grok-аккаунты, объявления.

## Таблица (стол)

### Поиск и фильтры
- Поиск ищет по **тому, что видно**: по названиям статусов/ответственных, по отформатированным
  датам, а не только по внутренним значениям. Совпадения **подсвечиваются** в ячейках.
- `Ctrl+F` фокусирует поиск стола, крестик очищает, Esc сбрасывает.
- **Панель активных фильтров** под тулбаром: чипы «поиск», «статус», «фильтр столбца
  (скрыто N)», «группировка», «сортировка» — каждый снимается одним нажатием, есть
  «Сбросить всё» и счётчик «12 из 40».
- **Фильтр столбца** переписан: поиск по значениям, счётчик строк у каждого значения,
  «Все / Ничего / Инвертировать», «только» при наведении, цветные точки для статусов,
  правильная сортировка (по порядку статусов / по числу / по дате). Исправлен баг:
  фильтр статус-столбца раньше не срабатывал (сравнивал подпись с внутренним id).
- Чипы статусов в тулбаре показывают **количество строк** и цветную точку.
- Контекстное меню ячейки: «Показать только с таким значением» / «Скрыть строки с таким значением».
- «Ничего не найдено» теперь объясняет, сколько строк скрыто, и предлагает «Сбросить фильтры».

### Заголовки столбцов
- Меню столбца: **Сортировка (↑/↓/нет)**, **Фильтр по значениям…**, **Снять фильтр**,
  **Группировать по столбцу**, **Выделить столбец**, **Подогнать ширину**,
  **Добавить столбец справа**, переименование, тип, варианты, скрыть/показать, дублировать, удалить.
- **Переименование прямо в заголовке** — двойной клик по названию.
- Заголовок подсвечивается, когда столбец отсортирован / отфильтрован / группирует;
  иконка типа, подсказка при наведении (тип, сортировка, итог).
- «Скрыто: N» в тулбаре — теперь меню со списком скрытых столбцов и «Показать все».
- «Подогнать ширину всех столбцов» в меню «Ещё».

### Итоги (нижняя строка)
- Каждый столбец умеет показывать свой **итог по выбору**: Сумма / Среднее / Минимум /
  Максимум / Медиана / Готово (сумма) / Строк / Заполнено / Пусто / Уникальных /
  % заполнено / Самая ранняя / Самая поздняя дата. Клик по ячейке итога — выбор,
  выбор запоминается для каждого стола/вкладки.
- Выделение диапазона показывает Σ, среднее и число ячеек (подсказка на счётчике строк).
- Заголовок группы при группировке показывает **сумму по группе** и долю «Готово»,
  прилипает к левому краю при горизонтальной прокрутке; в меню — «Свернуть/Развернуть все группы».

### Ввод данных
- Числа и суммы нормализуются при сохранении: `1 500,50`, `2.000`, `12 000 ₸`,
  `1.234.567,89` → одно каноническое число; сортировка, итоги и Excel-вставка работают одинаково.
  Если введено не число — предупреждение, текст сохраняется как есть.
- `Shift+Enter` — сохранить и остаться в ячейке; Enter — сохранить и вниз.
- Телефон и email рендерятся с кнопками «позвонить» / «написать»; email с ошибкой подсвечен.
- Календарь даты: кнопки **Вчера / Сегодня / Завтра**, клик по названию месяца — к текущему.
- Enter / Space на ячейке статуса, ответственного или даты **открывает список / календарь**
  с клавиатуры; после закрытия фокус возвращается в таблицу (стрелки больше не
  открывают список повторно).
- Правый клик больше не запускает редактирование ячейки.

### Клавиатура (см. «?» — обновлённая подсказка)
- `Ctrl+A` — выделить все ячейки; `Ctrl+↑↓←→` — к краю таблицы; `PgUp/PgDn` — на экран;
  `Ctrl+Home/End` — первая/последняя ячейка; `Space` — открыть карточку строки;
  `Esc` — снять выделение строк.

### Карточка строки
- Теперь **редактируемая**: любое поле правится прямо в карточке (текст, числа, статус,
  ответственный, дата, ссылка), сохраняется с undo.
- Навигация **← / →** между строками, счётчик «3 / 40», кнопки «Отметить Готово»,
  «Дублировать», «Удалить», дата создания/изменения.
- Открывается по `Space`, из контекстного меню, двойным кликом по номеру строки,
  из канбана (кнопка на карточке или двойной клик).

### Массовые действия (выбранные строки)
- Панель: Статус · Готово · **Заполнить** (ответственный и кастомные поля) · Копировать ·
  Дублировать · CSV выбранных · Удалить · «N / всего» — клик выбирает все строки в фильтре.
- Контекстное меню при нескольких выбранных строках содержит эти же действия.

### Канбан
- Сумма в шапке каждой колонки, сворачивание колонок, дата и телефон на карточке,
  подпись «Пусто», кнопка «Открыть карточку» на каждой карточке, ховер-эффект.

### Экспорт
- CSV выгружает подписи статусов и отформатированные даты (а не внутренние id).
- «Копировать таблицу (для Excel)» — вся отфильтрованная таблица в буфер как TSV.

### Разное
- Постраничный режим включается из «Ещё → Постранично»; нижняя панель страниц
  показывается только когда он включён (по умолчанию — «Все», панели нет).
- Дизайн: активная ячейка с мягким свечением, диапазон, подсветка заголовков, стеклянная
  панель массовых действий, градиентная строка итогов, аккуратные чипы, стили групп.
- Breakpoint `xs` (420px) добавлен в Tailwind — классы `xs:` в тулбаре теперь работают.
